# ADR-005: Портативный конфиг (OneDrive), область Linux и встроенный AI-апдейтер

- **Статус:** Принято

## 1. Произвольный путь к `split_tunnel.json` (OneDrive / синхронизация между ПК)
- Локальный файл-указатель `%AppData%/PWDTT/split_tunnel_bootstrap.json` хранит выбранный пользователем путь (например, `C:\Users\<User>\OneDrive\PWDTT\split_tunnel.json`).
- При сохранении префиксы путей приложений автоматически сворачиваются в переменные окружения (`%ProgramFiles%`, `%LocalAppData%`, `%AppData%`, `%UserProfile%`), чтобы один файл работал на ПК с разными именами пользователей.
- Предусмотрены retry при кратковременной блокировке файла клиентом OneDrive и локальный резервный кэш.

## 2. Поддержка Linux
- **Решение:** НЕ включать Linux Split Tunneling в v1.
- **Причина:** В Linux нет WinDivert/WFP/Wintun — потребуется отдельный стек (`cgroup v2` + `nftables`/`eBPF` + `ip rule` + адаптер к `wireguard-tools`), что удваивает сложность разработки и тестирования.
- **Готовность к будущему:** Заглушка `service_stub.go` сохраняет сборку Linux, а интерфейс `TrafficRouter` позволяет добавить Linux-бэкенд в v2 без переписывания настроек и UI.

## 3. Встроенный блок обновлений upstream и AI-отчёт (M6)
- В бинарник при сборке вшивается тег базового релиза `luminescq/PWDTT` (`base_upstream_tag`).
- В UI доступен блок: проверка новых релизов, попытка автообновления (бинарный релиз форка или безопасный dry-run merge/build во временном `git worktree`), сохранение подробного Markdown-отчёта для ИИ-агента и кнопка «Открыть отчёт в редакторе».
